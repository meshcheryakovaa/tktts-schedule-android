# Расписание ТКТТС — Android APK

Нативная Android-обёртка над веб-интерфейсом расписания.

## Что изменено

- Интерфейс находится в `app/src/main/assets/index.html`.
- При открытии приложение **не подключается** к `rasp.tktts.ru`.
- Подключение выполняется только после нажатия **«С сайта»**.
- В APK запросы выполняются нативным `HttpURLConnection`, а не `fetch()` из WebView, поэтому CORS не применяется.
- Разрешены сетевые запросы только к `https://rasp.tktts.ru`.
- Группы скачиваются последовательно с паузой и повторными попытками.
- Окно диагностики показывает `Android HTTP bridge: доступен` и результаты каждого запроса.
- Загрузка локального JSON через кнопку `JSON` поддерживается.
- Встроенного старого расписания нет: стартовый экран не инициирует сетевых запросов.

## Сборка

GitHub Actions автоматически собирает debug APK при push в `main`.

Артефакт workflow: `tktts-schedule-debug-apk`

Локально проект можно открыть в Android Studio и выполнить:

`Build > Build APK(s)`

Минимальная версия Android: 6.0 (API 23).
